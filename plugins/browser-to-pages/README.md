# 网页导入 Pages

把用户指定的网页、文章或课程章节导入 GPT Pages 的子页面。正文保持可编辑；代码保留缩进、空行和语言；图片和动画上传为 Pages 附件。

使用示例：

> 把这个网页导入我的 Pages 父页面，保留代码格式，图片上传为附件。

> 导入这个课程的第 5–20 章，已经完成的章节跳过。

安装后运行插件 setup，检查当前会话的 Browser、Pages 及文件处理工具。插件不会创建这些服务的连接，不会复制电脑登录态，也不提供独立云端抓取服务。需要登录的来源应在实际执行的浏览器中完成登录。

脚本支持 8 路图片下载、默认 4 路附件上传、缓存去重和断点续传。只包含通用转换逻辑，不绑定 Mac 路径。`import-job.mjs` 通过适配器调用当前环境的 Pages 和存储工具；Codex 专用示例不是手机端的运行要求。

已验证：正文与代码保留、缓存、并发上限、失败后保留成功附件、已完成内容跳过及现有改动保护。验证使用本地工具适配器和合成测试；ChatGPT 工作区实际导入及手机端完整流程需要在对应账户中验证。
